## 🔬 연구소 연결 (Research Lab Connection)

이 저장소는 **[mulberry-research-lab](https://github.com/wooriapt79/mulberry-research-lab)** 에서 설계한 스펙을 실제 코드로 구현합니다.

| 저장소 | 역할 |
|--------|------|
| [mulberry-research-lab](https://github.com/wooriapt79/mulberry-research-lab) | 🔬 Agent Passport, 공유 도구 레이어, A2A 프로토콜 연구 |
| [mulberry-](https://github.com/wooriapt79/mulberry-) | 🌟 Mission Control 메인 서버 |

### 연결 구조
```
mulberry-research-lab (연구·설계)
        ↓  스펙 → 코드
mulberry-auto-code-pilot (자율 실행)
        ↓  결과 → 기록
mulberry- (운영 서버)
```

> LAB의 연구 결과가 이슈로 등록되면, Auto Code Pilot이 자동으로 코드를 생성·검증·보고합니다.
